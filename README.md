# Personal Portfolio

My personal portfolio website, created to present my background, experience, projects and technical skills in one place.

The website was built with React and TypeScript and serves as a central hub for my professional profile, with a particular focus on Software Development, Data and Artificial Intelligence.

## About

I created this portfolio to provide a more complete view of my experience beyond a traditional résumé.

The website brings together information about my academic background, professional experience, technical skills and some of the projects I have developed throughout my studies and work.

## Features

- Professional introduction
- Work and academic experience
- Featured projects
- Technical skills
- Responsive interface
- Dark mode
- Animations and transitions
- Contact and professional links

## Technologies

- React
- TypeScript
- Vite
- Material UI
- Framer Motion

## Running Locally

Clone the repository:

```bash
git clone https://github.com/lucasedglima/portfolio.git
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```
